Connect Claude

Cloak runs Claude through Claude Code, Anthropic's official app. Two quick steps, about 3 minutes.

You'll need: a Claude Pro or Max plan (the free plan doesn't include Claude Code; see plans), or an Anthropic API key.
1
Install Claude Code
Checking…

A PowerShell window opens and runs Anthropic's official installer. It takes about a minute, and Cloak ticks this step off by itself when it's done.

Nothing happened?Open PowerShell yourself, paste this line and press Enter: irm https://claude.ai/install.ps1 | iex

2
Sign in with your Claude account
  1. Click Sign in. Your browser opens on Claude's sign-in page (a small window also opens; leave it be).
  2. Sign in with the account that has Pro or Max, then click Authorize.
  3. Come back here. Cloak notices by itself and ticks this step off.
Having trouble?

The browser showed a code: copy it, click into the small window, paste it and press Enter.

It says you don't have access: that account doesn't have Pro or Max. Upgrade at claude.ai, or use an API key instead (above).

Still stuck: shows exactly what's wrong.

2
Add your API key

Create a key at console.anthropic.com (Settings, then API keys) and paste it here. It's stored encrypted on this PC and only used to run Claude.

Pick a starting mode

A mode changes how Claude helps and which shortcut buttons you see. Switch anytime from the chat bar, or by right-clicking the top widget.

Quick tour

The essentials. Try any of them now.

ChatHover the widget at the top of your screen, or press Ctrl+Shift+Space. Replies stream in as Claude writes.
Ask about your screenPress Ctrl+Shift+S, or use a shortcut button like "Explain my screen".
Tasks and NotesWrite to-dos in Notes and they appear in Tasks. Drag panels anywhere and resize them from any edge.
What did I just do?Lost focus? One click recaps the last half hour and where you left off.
You approve changesClaude reads and searches on its own, but asks before changing anything. Tick "Always allow" for things you trust.
Make it yoursIn Settings: colors, the top widget, modes, shortcut buttons, and widgets Claude builds for you, like a calendar.
